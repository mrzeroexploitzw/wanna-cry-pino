# GitHub publishing checklist

Recommended repository name: `THANXIE-AI`

Recommended short description:

> A modular WhatsApp AI community assistant powered by the official Meta WhatsApp Business Platform — self-service registration, 185-command registry, moderation, Pino Pino, premium-ready accounts and customizable language/slang.

Before publishing:

- [ ] Review `.env.example` and never commit `.env`.
- [ ] Set repository topics: `whatsapp`, `meta-whatsapp-cloud-api`, `whatsapp-bot`, `nodejs`, `sqlite`, `ai`, `community-bot`, `thanxie-ai`.
- [ ] Configure the repository homepage and About text.
- [ ] Add a repository social preview using `assets/branding/thanxie-default.png` if desired.
- [ ] Enable Issues and Discussions if the community will use them.
- [ ] Protect the default branch and require CI to pass.
- [ ] Create a GitHub release for `v1.2.0` after production verification.
